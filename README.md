# Personal Portfolio Website

A simple personal portfolio website developed using **HTML5 and CSS3**. The website is designed to showcase my profile, skills, projects, and provide a way for visitors to contact me.

## Pages

* **Home** – Introduces my profile and provides information about my skills, projects, and interests.
* **Contact** – Provides contact information and a way for visitors to get in touch with me.

## Technologies Used

* HTML5
* CSS3

## Features

* Simple and clean design
* Easy navigation between pages
* Home page for portfolio information
* Contact page for communication
* Basic responsive layout
* Beginner-friendly HTML and CSS implementation

## Purpose

This project was created to strengthen my **HTML and CSS skills** and to build a simple online portfolio for showcasing my technical background and projects.
